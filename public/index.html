Terms & Security Policy

1. Zero-Trust Access Boundaries: Every request requires a valid, digitally signed JWT. No document metadata or physical files are exposed via public static directories.

2. Immutable Forensics: All operations (including blocked unauthorized access and cross-tenant attempts) are permanently recorded in the forensic audit trail with non-repudiation.

3. Cryptographic Storage: Uploaded attachments are sanitized against directory traversal (CWE-22) and restricted strictly to authorized clearance roles.
